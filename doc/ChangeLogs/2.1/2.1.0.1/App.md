# 2.1.0.1

> [!important]
> ClassFabric 是基于 ClassIsland 的个人精简定制版本，面向班级电教场景打造。在开始使用前，建议先了解上游 ClassIsland 的基本用法：https://github.com/ClassIsland/ClassIsland

2.1 - KapoKali（卡利白）

这是 ClassFabric 的首个公开发布版本。在本版本中，ClassFabric 完成了品牌独立与面向电教场景的定制化改造，并带来了全新的岛式竖版课表与竖条上下课提醒。

## 🚀 新增功能与优化

- 【课表】新增岛式竖版课表（Beta）：贴屏幕左右缘停靠的连续胶囊窗口，等高盲字格展示当日课程，已过节淡显
- 【课表】竖条支持停靠方向、垂直偏移、截面宽度、界面缩放、独立圆角、换课高亮与自定义前景色
- 【课表】全天进度细轨：按当日课时进度实时推进，与课程序列严格对齐
- 【提醒】竖条上下课提醒（Beta）：课间轮播下课提示与下节预告，临上课 60 秒自动进入预告，整段强调色演出
- 【设置】新增竖条课表设置区，集中管理上述能力
- 【插件】恢复插件市场：在线安装与更新、镜像源管理、自定义插件源
- 【主题】恢复主题市场：市场页签、在线安装与更新
- 【调试】「启动调试模式」入驻设置右上角更多菜单的「实验性功能」
- 【应用】启用自有版本代号体系，本版本代号 KapoKali（卡利白）
- 【设置】开源提示中的源代码仓库地址指向 ClassFabric 仓库

- 修复 Windows 10 下亚克力溢出圆角的问题
