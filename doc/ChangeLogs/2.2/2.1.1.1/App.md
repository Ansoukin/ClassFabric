# ClassFabric 2.2 - MikHail（米哈伊尔） Developer Preview 1

这是 ClassFabric 2.2 “MikHail（米哈伊尔）”的首个开发者预览版本。

在此版本中，我们正式将项目重命名为 ClassFabric，新增了 ClassIsland 插件兼容层，并修复了档案编辑器中的一个问题。开发者预览版本可能仍存在不稳定或功能不完整的情况，建议在测试环境中使用。

## 🚀 新增功能与优化

- 【插件】新增 ClassIsland 插件兼容层，并将应用重命名为 ClassFabric（[9786a68](https://github.com/Ansoukin/ClassFabric/commit/9786a685d1c2aa71c43d54f55ab01add9ae5abda）) by [**@Ansoukin**](https://github.com/Ansoukin)
- 【应用】将控制台 ASCII 艺术字更新为 ClassFabric（[5387f5f](https://github.com/Ansoukin/ClassFabric/commit/5387f5f3)）by [**@Ansoukin**](https://github.com/Ansoukin)
- 【API/课程】增加获取某日课程安排的 API（[8a6dc18](https://github.com/ClassIsland/ClassIsland/commit/8a6dc18d21a319d5d34346d71684cf8fe44b6e1e)）by [**@HelloWRC**](https://github.com/HelloWRC)
- 【档案编辑器】添加日程课表编辑器（[27f2655](https://github.com/ClassIsland/ClassIsland/commit/27f2655cfa30e51c4aeb3ae895e50dee953e40b2)）by [**@HelloWRC**](https://github.com/HelloWRC)
- 【UI】添加图片 IconSource 对应的图标表达式（[8307554](https://github.com/ClassIsland/ClassIsland/commit/83075546d62a45ba6db571871d1fb078568e9af7)）by [**@HelloWRC**](https://github.com/HelloWRC)
- 【UI】添加图标选择器（[4554c57](https://github.com/ClassIsland/ClassIsland/commit/4554c57ba11deabaee34a55190db00be34fc53c9)）by [**@HelloWRC**](https://github.com/HelloWRC)
- 【通知】为提醒行动添加自定义图标支持（[b61a035](https://github.com/ClassIsland/ClassIsland/commit/b61a0353282cc061dc4f498d515bfd3b9a38ca58)）by [**@HelloWRC**](https://github.com/HelloWRC)
